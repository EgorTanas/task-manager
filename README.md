# Task Manager

## Analiza structurii proiectului

### 1. Care este rolul folderului `src`?

Folderul `src` conține codul principal al aplicației. Aici se află componentele React, fișierele JavaScript și fișierele CSS ale proiectului.

### 2. Ce reprezintă fișierul `App.jsx`?

`App.jsx` este componenta principală a aplicației React. În acest fișier este definită interfața principală și sunt folosite celelalte componente ale aplicației.

### 3. Ce informații sunt păstrate în `package.json`?

Fișierul `package.json` conține informații despre proiect, comenzile pentru rularea aplicației și dependențele necesare pentru funcționarea proiectului.

### 4. Ce reprezintă folderul `node_modules`?

Folderul `node_modules` conține toate pachetele și bibliotecile instalate cu npm, de care proiectul are nevoie pentru a funcționa.
